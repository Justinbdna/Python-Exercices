# Python pour l'analyse de données

Ce dépôt contient les exercices pratiques du module **Python pour l'analyse de données**. Il couvre les fondamentaux de la programmation en Python jusqu'à l'exploration, l'analyse et la visualisation de jeux de données avec **pandas**, **Matplotlib** et **Seaborn**.

## 📁 Arborescence des exercices

```text
python-exercices/
├── exercice-01/
│   └── exercice.py          # Exercice 01 : Variables et calculs
├── exercice-02/
│   └── exercice.py          # Exercice 02 : Classer avec des conditions
├── exercice-03/
│   └── exercice.py          # Exercice 03 : Une semaine de températures (listes et boucles)
├── exercice-04/

```

## 🛠️ Configuration de l'environnement

1. **Création de l'environnement virtuel :**
   ```bash
   python3 -m venv .venv
   ```

2. **Activation de l'environnement virtuel :**
   - Sur macOS/Linux :
     ```bash
     source .venv/bin/activate
     ```
   - Sur Windows :
     ```bash
     .venv\Scripts\activate
     ```

3. **Installation des dépendances :**
   ```bash
   pip install -r requirements.txt
   ```
